## Goal
A simple, pleasant interface: upload, chat, click a citation to see the page text.

## Steps
1. `ui/app.py` with Streamlit: file uploader, chat input, message history.
2. Each answer shows its pages as buttons; clicking one shows that page's text in a side panel.
3. Show a spinner while waiting and a friendly message when the API is down.

## Acceptance criteria
- [ ] `streamlit run ui/app.py` works against the local API.
- [ ] A 30-second screen recording or 3 screenshots in the PR.
- [ ] No API keys in the UI code; the UI only talks to your FastAPI.
